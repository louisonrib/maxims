# maxims

Agent skills, one famous maxim each. The maxim names a habit everyone
already knows; the skill turns it into a discipline your agent follows at
the moment it matters.

| Skill | Maxim | What your agent does |
|---|---|---|
| [`shoulders-of-giants`](skills/shoulders-of-giants) | *"If I have seen further it is by standing on the shoulders of Giants."* — Isaac Newton | Before making anything — a design, code, a process, a document format, a product decision — it looks at what already exists, reads the best examples, tells you what it takes and what it leaves, then builds on them instead of starting from a blank page. |

## Install

```
npx skills add louisonrib/maxims
```

Or copy a skill folder from `skills/` into `~/.claude/skills/`.
